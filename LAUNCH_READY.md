## 🚀 Quick Start

### Run the Blockchain

```bash
cd synapsechain
node demo.js
```

Output:
```
✅ Genesis block created
✅ 4 validators added (45,000 SYN stake)
✅ Blocks mined with HotStuff consensus
✅ Block-STM parallel execution (17-20x speedup)
✅ AI agents analyzing and optimizing
```

### Start the API Server

```bash
cd synapsechain
node api.js
```

Access:
- API: `http://localhost:3001/api`
- WebSocket: `ws://localhost:3001`

### Launch the Website

```bash
cd synapsechain/website
npm install
npm run dev
```

Access: `http://localhost:3000`

Pages:
- `/` - Landing page
- `/explorer` - Block explorer
- `/governance` - AI governance dashboard with live debates
